Privacy Policy

Awesome Input

Awesome Input is a client-side Chrome extension for supported AI chat services. It adjusts keyboard behavior inside supported web composers so Enter inserts a new line and Cmd+Enter or Ctrl+Enter sends a message.

Last updated: March 1, 2026

Data Handling

  • We do not collect personal information, prompts, or chat content.
  • We do not collect usage analytics.
  • We do not transmit data to external servers.
  • We do not store user input in extension-managed storage.
  • We do not use advertising, profiling, or third-party tracking.

Permissions Scope

  • The extension runs only on the URLs declared in the extension manifest.
  • It reads page DOM state only to detect the composer and send controls needed for its keyboard shortcuts.

Support

For support or privacy questions, use the repository issue tracker or the support contact listed in the Chrome Web Store entry.
