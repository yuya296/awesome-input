# Privacy Policy

Awesome Input is a client-side Chrome extension for supported AI chat services.

## Data Handling

- The extension does not collect personal information, prompts, chat content, or usage analytics.
- The extension does not transmit data to external servers.
- The extension does not store user input locally in extension-managed storage.
- The extension does not use advertising, profiling, or third-party tracking.

## Permissions Scope

- The extension runs only on the URLs declared in `src/manifest.json`.
- The extension reads page DOM state only to detect the composer and send controls required for its keyboard shortcuts.

## Contact

For support or privacy questions, use the repository issue tracker or the support contact listed in the Chrome Web Store entry.
