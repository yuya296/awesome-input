# プライバシーポリシー

Awesome Input は、対応する AI チャットサービス上で動作するクライアントサイドの Chrome 拡張です。

## データの取り扱い

- 個人情報、プロンプト、チャット内容、利用状況の解析データを収集しません。
- 外部サーバーへデータを送信しません。
- 拡張機能のストレージにユーザー入力を保存しません。
- 広告、プロファイリング、サードパーティトラッキングを行いません。

## 権限の範囲

- 拡張機能は `src/manifest.json` に定義した URL でのみ動作します。
- キーボードショートカットを実現するため、入力欄と送信 UI の検出に必要な範囲でのみ DOM 状態を参照します。

## 連絡先

サポートやプライバシーに関する問い合わせは、リポジトリの issue tracker または Chrome Web Store のサポート連絡先を利用してください。
