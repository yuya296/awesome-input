Chrome Extension

Awesome Input

Awesome Input makes AI chat input feel natural. Use Enter for a new line, and use Cmd+Enter or Ctrl+Enter to send your message.

Privacy Policy View Repository

What It Does

  • Insert a new line while writing prompts Enter
  • Send only when you mean to Cmd/Ctrl+Enter

Supported Sites

  • ChatGPT
  • Gemini

The extension works directly in supported web composers and does not require account linking or extra setup.

What It Does Not Do

  • It does not collect prompts or chat content.
  • It does not send data to external servers.
  • It does not use analytics, ads, or third-party tracking.

Important Notes

  • Site UI changes may affect composer or send button detection.
  • Claude is not supported at this time.
  • This extension is not affiliated with OpenAI or Google.

Need help? Use the repository issue tracker or the support contact listed in the Chrome Web Store entry.
